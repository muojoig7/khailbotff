## الصلاحيات: المالك والأدمن خارج كل البوابات

المالك (`FACTORY_OWNER_ID`) والأدمنية **لا تنطبق عليهم**:
قنوات الاشتراك · فحص الدولة · قائمة الحظر · حالة «بانتظار الموافقة».

يكتب المالك `/start` فتُفتح **لوحة المالك مباشرة**، ويصل للواجهة العادية
بزر «↩ رجوع للواجهة». ولو أرسل رقماً من دولة غير مسموحة يُقبل بلا سؤال.

## رحلة المستخدم

```
/start
  ↓
إشعار فوري للمالك (الاسم + اليوزر + الآيدي + المصدر) مع أزرار [اسمح][ارفض][حظر]
  ↓
قنوات الاشتراك (إن وُجدت) ← زر «تحقّقت من الاشتراك» (فحص فعلي للعضوية)
  ↓
📱 مشاركة الرقم (كيبورد طلب اتصال)
  ↓
فحص مفتاح الدولة:
   ✅ مسموح  → تحقق + نقاط إحالة لصاحب الرابط + الواجهة
   🚫 غير مسموح → «راسل المالك» + إشعار للمالك بزر [اسمح له بالعبور]
  ↓
الواجهة: إنشاء بوت · بوتاتي · الدعم · الإحالة (+ لوحة المالك للأدمن)
```

**الحالات محفوظة في القاعدة**، فإعادة تشغيل البوت لا تُفقد أحداً في المنتصف.

### نقاط تصميم مهمة

- **الدولة من الرقم**: تيليجرام لا يعطي دولة الحساب؛ نستخدم مفتاح الاتصال
  (+964…) ونحفظ **مفتاح الدولة + آخر 4 أرقام فقط**، لا الرقم كاملاً.
- **نرفض رقم غير المستخدم**: إن لم يطابق `contact.user_id` المرسل، يُرفض الطلب.
- **نقاط الإحالة لا تُعطى عند الدخول** — فقط بعد التحقق بالرقم.
- **المستثنى إدارياً لا يُحتسب إحالة** (كما طلبت).
- **لا نقاط سالبة أبداً** — أي خصم يتجاوز الرصيد يفشل ويُعاد كما كان.

## إنشاء بوت

الترتيب المتفق عليه: **تحقق من التوكن ← أنشئ البوت ← اخصم النقاط**.
ولأن الخصم أخيراً، فلو فشل لأي سبب يُحذف السجل فوراً حتى لا يبقى «بوت يتيم».

- النقاط تُخصم عند الإنشاء.
- التوكن يُشفَّر (Fernet) ويُحذف من المحادثة لحظة قراءته.
- البوت مسجّل بـ 30 يوماً (أو مدة الوضع المجاني)، ويظهر في «بوتاتي» مع الأيام المتبقية.
- التجديد يخصم نفس السعر ويضيف المدة فوق المتبقي.
- الإطفاء بعد الانتهاء: فترة سماح 4 ساعات ثم `expired` (خيط خلفي كل 5 دقائق).

## لوحة المالك

تظهر لمن يكتب `/start` وهو المالك (`FACTORY_OWNER_ID`) أو أدمن مضاف.

| الزر | الوظيفة |
|---|---|
| 💵 الإعدادات | سعر البوت · نقاط الإحالة · مدة البوت · مدة المجاني · فترة السماح · تشغيل/إطفاء التحقق وفحص القنوات والدولة وإشعار الدخول |
| 📢 القنوات | إضافة/حذف قنوات الاشتراك + **فحص القنوات** (يكشف إن كان البوت ليس مشرفاً) |
| 🌍 الدول | إضافة/حذف مفاتيح الاتصال المسموحة |
| ✅ الاستثناءات | إضافة/حذف من يعبر بلا فحص دولة |
| 👤 الأدمنية | رفع/إزالة أدمن (نفس صلاحياتك) |
| 💎 النقاط | إضافة/خصم نقاط لأي مستخدم (لا سالب) |
| 📊 الإحصائيات | أرقام كاملة + **قمع التحويل** (قنوات ← رقم ← تحقق) |

كل زر إداري يفحص الصلاحية أولاً، ويرفض غير المصرح برسالة واضحة.

## المرحلة 2 — تشغيل بوت العميل فعلياً

المصنع **لا يستورد** كود بوت الحماية، ولا يعدّل فيه سطراً. يشغّله كعملية
مستقلة لكل عميل:

```
data/instances/t12/
    data/alkhal.db     قاعدة العميل (خاصة به)
    bot.log            سجله
    instance.json      معلومات النسخة (بلا توكن)
```

### التجهيز (مرة واحدة)

> **مهم:** بدون هذه الخطوة لا يعمل أي بوت — البوت يُسجَّل ويُخصم رصيده لكن
> التشغيل ينتظر كود التشغيل.
>
> **تلقائي:** ضع ملف `alkhal_bot_v6_2.zip` بجانب المصنع وأعد تشغيله — سيفكّه وحده.
> **يدوي:** `python3 setup_runtime.py alkhal_bot_v6_2.zip`
> **من تيليجرام:** لوحة المالك ← 🧩 كود التشغيل ← «إعادة الفحص / تجهيز»

```bash
python3 setup_runtime.py /path/to/alkhal_bot_v6_0.zip
python3 setup_runtime.py          # للتحقق فقط
```

يفكّ الأرشيف في `runtime/`، ويرفض المسارات المشبوهة، ويحذف أي قاعدة بيانات
قديمة تأتي مع الأرشيف. تغيير المجلد: `FACTORY_RUNTIME_DIR`.

### ما يحدث عند «إنشاء بوت»

1. تحقق من التوكن (`getMe`)
2. إنشاء السجل + خصم النقاط
3. **تجهيز مجلد النسخة + تشغيل العملية** فوراً
4. البطاقة تُظهر الحالة الحقيقية (🟢 يعمل / 🟡 غير متصل / ⚠️ خطأ)

### المشرف (Runner)

خيط داخل بوت المصنع، كل 15 ثانية:

| الحالة | الإجراء |
|---|---|
| نسخة نشطة لكن عمليتها ماتت | إعادة تشغيل تلقائية |
| تكرر التوقف 5 مرات في 10 دقائق | إيقاف + حالة `error` بسبب مسجّل |
| تجاوزت الانتهاء + فترة السماح (4 ساعات) | إيقاف + `expired` |
| موقوفة يدوياً من العميل | لا يلمسها |
| معلّقة (كود التشغيل غير جاهز) | يحاول تشغيلها عند توفره |

### أزرار العميل في «بوتاتي»

`▶️ تشغيل` · `⏸ إيقاف` · `🔄 تجديد` · `🗑 حذف` — والحذف يوقف العملية ويمسح
مجلد النسخة كاملاً بعد تأكيد الملكية.

### لوحة المالك ← 🤖 البوتات

كل بوتات العملاء: الحالة، الأيام المتبقية، وأزرار تشغيل/إيقاف/تمديد 30 يوماً
لأي بوت.

### إصلاح مهم في هذا الإصدار

كانت لوحات الأزرار تُرسل كقواميس عادية، وتيليجرام يرفضها:

```
Bad Request: can't parse reply keyboard markup JSON object
```

السبب: `pyTelegramBotAPI` يقبل كائنات فقط (`InlineKeyboardMarkup`) ويحوّلها
بـ `to_json()`؛ القاموس العادي يصل كنص غير صالح. أُضيفت `ui.markup()` وتحوّل
كل كيبورد قبل الإرسال، مع اختبار يمنع رجوع الخطأ.

## المرحلة 3 — البث، الوضع المجاني برسالة، الإشعارات، التنظيف

### 📣 البث (مستخدمون + مجموعات)

- **طابور محفوظ في القاعدة** (`broadcasts` + `broadcast_queue`)، فلو أُعيد تشغيل
  المصنع يكمل من حيث توقف ولا يكرر رسالة.
- **حد 20 رسالة/ثانية** احتراماً لتيليجرام، مع احتساب الوقت الفعلي.
- **المجموعات تُبثّ ببوت كل عميل** لا ببوت المصنع (المصنع ليس عضواً في
  مجموعات العملاء). لكل صف في الطابور «عبر من».
- **تقرير تلقائي** لك عند الانتهاء: الهدف · وصل · فشل · حظر/محذوف.
- تصنيف ذكي للفشل: `blocked` (حظر البوت) منفصل عن `failed` (خطأ آخر).
- إلغاء بث جارٍ بضغطة.

### 🆓 الوضع المجاني برسالة إلزامية

الضغط على «تفعيل + إعلان» ← يطلب منك النص ← يعرض عدد المستلمين ← تؤكد ←
**يبثّ الرسالة ويُفعّل الوضع** فوراً. وإيقاف الوضع لا يوقف البوتات التي أُنشئت فيه.

### 🔔 إشعار التفعيل

عندما يفعّل العميل بوتَه في مجموعته (`تفعيل`)، المشرف يقرأ اسم المجموعة من
قاعدة البوت ويُرسل إشعاراً **مرة واحدة**: للعميل («بوتك صار يعمل») ولك
(«بوت تفعّل في مجموعة»).

### 🧹 حذف بيانات المنتهية

البوت المنتهي يبقى 30 يوماً (للتجديد)، ثم تُحذف ملفاته وصفّه، ويُسجَّل في جدول
`purged` للأثر.

## المرحلة 4 — تحديث ZIP (المالك فقط)

### كيف ترفع تحديثاً

```bash
# 1) ابنِ ملف إصدار من مشروع البوت
python3 tools/make_release.py ../alkhal_bot_v6_1.zip 6.1.0

# 2) ارفع الملف الناتج لبوت المصنع في الخاص (ZIP فقط)
#    سيُفحص ويُنشر تلقائياً ويصلك تقرير
```

### ما يحدث للملف (بالترتيب)

| # | المرحلة | لو فشلت |
|---|---|---|
| 1 | فحص الملف: الحجم (≤25م) · ZIP صالح · `main.py` موجود · رفض المسارات المطلقة و`..` والروابط الرمزية وملفات `.key/.db/.env` | رفض فوري، لا شيء يتغيّر |
| 2 | فكّ في مجلد مؤقت `_staging` — لا يلمس الإصدار الشغّال | حذف المؤقت |
| 3 | فحص صياغة كل ملفات `.py` + وجود `tests/` | رفض |
| 4 | **بوابة الاختبارات**: تشغيل اختبارات الإصدار كاملاً (بمهلة 240ث) | رفض مع آخر 8 أسطر من الفشل |
| 5 | نسخة احتياطية: الكود الحالي + قاعدة المصنع في `data/backups` | توقف |
| 6 | **كناري**: بوت واحد ينتقل ويُعاد تشغيله، انتظار 8 ثوانٍ والتأكد أنه حيّ | **تراجع آلي** |
| 7 | **دفعات**: بقية البوتات 3 في كل دفعة بفاصل 3 ثوانٍ | **تراجع آلي للجميع** |

### التراجع

- تلقائي عند أي فشل بعد التبديل: كل بوت يرجع للإصدار السابق ويُعاد تشغيله.
- يدوي: زر «⏪ تراجع عن آخر نشر» في شاشة التحديث.

### ضمانات

- **الإصدار لكل بوت** (`bots.release`) — البوتات على إصدارات مختلفة أثناء الدفعات، وكل بوت يعمل من مجلد إصداره.
- **البيانات لا تُلمس**: `data/instances/*` خارج مجلدات الإصدارات، والتحديث لا يقرأها ولا يكتبها.
- **حالة النشر محفوظة** في جدول `deploys`؛ لو انقطع المصنع في المنتصف يُعلَّم النشر `interrupted` ويظهر لك.
- **تنظيف تلقائي**: يُحتفظ بآخر 3 إصدارات فقط.
- الملف يُقبل من **المالك فقط** (`FACTORY_OWNER_ID`)، لا من الأدمنية.

## 🐍 السكربتات — تشغيل ملفات بايثون (المالك فقط)

من لوحة المالك ← **🐍 السكربتات**:

- ابعت ملف `.py` أو أرشيف `.zip` فيه `main.py` — يُستورد فوراً.
- لكل سكربت: **▶️ تشغيل · ⏸ إيقاف · 📜 إخراج · 🗑 حذف**.
- الإخراج (stdout + stderr) يُحفظ في `out.log` ويُعرض آخر 60 سطراً.
- كل سكربت معزول في `data/scripts/s<id>/`، بحد ذاكرة 512 ميغا، وسقف 10
  سكربتات عاملة في نفس الوقت.
- الأرشيف يمر بفحص zip slip، ولا تُنقل ملفات `.key` أو `.env` من داخله.

## 📇 ملف العملاء (أرقام + توكنات)

عند مشاركة العميل رقمه يصلك **فوراً** في تيليجرام: الاسم، اليوزر، الآيدي، والرقم
كاملاً — مع زر «ملف العميل» وزر «حظر».

من لوحة المالك ← **📇 العملاء**:

- قائمة العملاء بصفحات، مع علامة 📱 لمن عنده رقم.
- **ملف العميل**: بياناته، رقمه مخفياً (`+964****67`)، نقاطه، وبوتاته.
- **إظهار الرقم كاملاً** بضغطة، و**🔑 توكن** أي بوت من بوتاته.
- **📤 تصدير CSV**: نسخة بالأرقام فقط، أو نسخة مع التوكنات (بتحذير).

الأرقام تُخزَّن **مشفّرة** في القاعدة، ولا تُفكّ إلا لك، وكل عرض أو تصدير
يُسجَّل في سجل التدقيق (من، متى، أي عميل).

## 🔑 التوكن

التوكن **يُخزَّن مشفّراً** (Fernet) في القاعدة، ويُفكّ **للمالك فقط** عند الطلب:
بطاقة البوت ← **🔑 عرض التوكن** ← يظهر في رسالة مع زر «🗑 حذف الرسالة».
كل عرض يُسجَّل في سجل التدقيق.

## الفحص التلقائي (CI)

`.github/workflows/ci.yml` يشغّل عند كل تعديل: فحص الصياغة ثم **112 اختباراً**
(بما فيها اختبارات النشر التي تشغّل اختبارات الإصدار الجديد).

ارفعه إلى GitHub — يعمل تلقائياً في تبويب Actions بلا أي إعداد.

---

## ما نُفّذ في هذه المرحلة

✅ الدخول + إشعار المالك الفوري + أزرار القرار
✅ قنوات الاشتراك + فحص العضوية + فحص صحة القنوات
✅ مشاركة الرقم + فحص الدولة + مسار الانتظار + الاستثناء الإداري
✅ الواجهة الأربعة + النقاط (دفتر حركات، بلا سالب)
✅ إنشاء البوت (تحقق ← إنشاء ← خصم، مع تراجع آمن) + بوتاتي + التجديد + الإطفاء
✅ الإحالة (بعد التحقق) + الدعم (تذاكر مع رد)
✅ لوحة المالك: الإعدادات · القنوات · الدول · الاستثناءات · الأدمنية · النقاط · الإحصائيات · الوضع المجاني
✅ الوضع المجاني (بوت واحد لكل مستخدم)
✅ **تحديث ZIP بأمان**: فحص · بوابة اختبارات · نسخة احتياطية · كناري · دفعات · تراجع آلي
✅ **البث** بطابور وتقرير (مستخدمون + مجموعات) · **الوضع المجاني برسالة إعلان** · **إشعار التفعيل** · **حذف بيانات المنتهية بعد 30 يوماً**
✅ **تشغيل بوت العميل فعلياً**: عملية مستقلة + قاعدة + سجل + إعادة تشغيل تلقائية + إطفاء بعد السماح + أزرار تشغيل/إيقاف/حذف + شاشة بوتات في لوحة المالك

## ما تبقّى (المراحل القادمة)

- **المرحلة 3**: البث (مستخدمون + مجموعات) بطابور وتقرير، والوضع المجاني مع
  رسالة إلزامية تُبثّ قبل التفعيل، وإحصائيات أعمق.

---

## ملاحظة أمنية

- كل توكن مشفّر بمفتاح `data/secret.key` — **انسخه في مكان آمن**؛ بلا المفتاح
  لا يمكن فك أي توكن.
- لا تُشارك حساب الخادم؛ التوكن يظهر في `/proc` لعملية بوت العميل (المرحلة 2).
- الأدمن يملك نفس صلاحياتك ما عدا رفع التحديث (المرحلة 4).
